## 🚀 Featured Projects

### 🩺 Women's Health & Fertility Assessment Platform (Web)

> A Next.js web platform delivering guided health-assessment journeys, scaled to 4,000+ active users.

**Highlights**

* 🏗️ Reusable, node-based health-assessment flow architecture
* ⚡ Layered caching (React `cache()` + Next.js `unstable_cache()`) — cut CMS API calls by ~95%
* 🔐 Mitigated a server-side XSS vulnerability in dynamically rendered CMS/API content
* 🔍 Dynamic, localized Google Merchant feeds for improved shopping-ad discoverability
* 📊 GDPR-compliant consent management with Google Consent Mode v2 and GA4 ecommerce tracking

**Tech Stack**

`Next.js` `React` `TypeScript` `Contentful` `GA4` `Google Consent Mode v2`
